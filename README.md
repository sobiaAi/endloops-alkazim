# Endloops website

Landing page for Endloops, built as an internship design-and-build assignment.

## Run it

```bash
npm install
npm run dev      # local development
npm run build    # production build in dist/
```

## Stack

React 19, Vite, Tailwind CSS v4 (design tokens in `src/index.css`), Manrope via Fontsource.

## Notes

- Sample data only: the invoice demo, figures and company names are illustrative.
- The forms validate input but do not send anything (no backend in this build).
